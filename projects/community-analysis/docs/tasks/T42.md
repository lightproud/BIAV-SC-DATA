# T42 候选发现与历史回放

```text
【工单 T42】候选发现与历史回放
阶段：4　依赖：T41
目标：从未归属池里找出新议题的候选，交给人收口；并按月回放历史。
产出：
- `src/yuqing/issues/discover.py`
- `tests/t42_discover_test.py`
规则：
1. 对未归属池按要点向量聚类。先用简单可解释的做法（相似度阈值的连通分量，或凝聚聚类），不强依赖特定库。
2. 一个簇同时满足 `min_points` 与 `min_authors` 才成为候选。
3. 从簇里取最多 30 条差异尽量大的要点，交 `MODEL_MID` 起名、写一句定义和“算什么、不算什么”的边界。
4. 候选写成 create 事件，状态为“候选”，等人批准。
5. `yuqing issues replay --from YYYY-MM --to YYYY-MM`：按月份顺序处理历史，使每个议题的首次出现时间为真。
验收（全部通过才算完成）：
- `pytest -q tests/t42_discover_test.py`：合成数据里预埋 3 个簇加噪声，能找回 3 个候选；门槛生效；首次出现时间正确
之后的人工闸门 G4（第一次收口）：人过目规模最大的前 50 个议题：合并、改名、驳回。之后每周一次。 这一步由人做，不要替人做。
完成后：提交、勾掉清单，接着做本阶段的下一张；阶段做完或遇到闸门再停。
```
