# T23 金标集工具

```text
【工单 T23】金标集工具
阶段：2　依赖：T22
目标：给人一套抽样、标注、评测的工具。及格线由人定，评测由机器跑。
产出：
- `src/yuqing/gold/`
- `config/thresholds.toml`（只放样例值，由人改）
- `tests/t23_gold_test.py`
规则：
1. 抽样：`yuqing gold sample --plan smoke|gold --seed 1`。smoke = 中、英、日各 100 个单元；gold = 2,000 个，按语言 × 渠道类型分层，层内随机，其中一成标为双人盲标。
2. 标注页：单文件 HTML，手机与电脑都能用；逐单元显示上下文与正文；可切换“盲标”（不显示模型预标）与“改标”（显示预标供修改）；结果导出为 JSON 文本。作者显示为段内代号。
3. 导入：`yuqing gold import` 写入 `DATA_ROOT/gold/<gold_ver>/`，只追加，记录标注人代号与轮次。
4. 评测：`yuqing gold eval --model …`，按语言 × 维度出指标——是否反馈的召回率与精确率；情绪、角度的一致率，并给出双人盲标子集上的人人一致率作对照；对象、自述身份与意向的精确率。
5. 反馈点对齐：模型与金标的 `anchors` 有交集，即视为同一个点。
6. 及格线读 `config/thresholds.toml`；不过线则退出码非零，报告里列出不过线的语言 × 维度。
7. 多模型对比：`--model a,b,c` 出一张对照表，含每千单元的估算成本。报告为 HTML。
验收（全部通过才算完成）：
- `pytest -q tests/t23_gold_test.py`：指标与手工算好的小样例一致；抽样同 seed 可复现；不过线时退出码非零
不要做：
- 不自己标金标；不改 `thresholds.toml` 的数值；不自己选模型。
之后的人工闸门 G2（金标集、及格线、选模型）：人先标 300 条冒烟，再标 2,000 条金标；裁定各维度及格线；看跑分对照表选模型。过线才允许全量回标。 这一步由人做，不要替人做。
完成后：提交、勾掉清单，接着做本阶段的下一张；阶段做完或遇到闸门再停。
```
