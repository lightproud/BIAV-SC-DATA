# T11 清洗打标

```text
【工单 T11】清洗打标
阶段：1　依赖：T10
目标：给不该送去标注的消息标上原因，但一条都不删。
产出：
- `src/yuqing/normalize/clean.py`
- `tests/t11_clean_test.py`
- 表 `msg_flags`、`clean_report.json`
规则：
1. 写单独的 `msg_flags` 表（按 `day_cn` 分区，带 `clean_ver`），不改 `messages`。
2. `drop_reason` 按顺序取第一个命中的：`bot`（字段标记，或在 `config/bots.txt` 里）→ `system`（入群、置顶等系统消息）→ `empty`（无文字无附件）→ `emoji_only`（只有表情、贴纸、标点）→ `dup_same_author`（同一作者 24 小时内在同一频道的完全相同文字，留第一条）→ `dup_long_repost`（60 字以上的完全相同文字出现多处，留最早一条）。
3. `image_only` = 有附件无文字。这类不算丢弃，也不送标注；计数保留，报告里单列。
4. 明确不做：不同作者发的相同短句（“+1”“同感”）不去重，那是声量。
5. `clean_report.json`：各原因的条数与占比。
验收（全部通过才算完成）：
- `pytest -q tests/t11_clean_test.py`：每条规则一组表驱动样例，含“不同作者相同短句不去重”“有图无字保留”两个反例
完成后：提交、勾掉清单，接着做本阶段的下一张；阶段做完或遇到闸门再停。
```
