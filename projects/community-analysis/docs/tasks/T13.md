# T13 试切检查包

```text
【工单 T13】试切检查包
阶段：1　依赖：T12
目标：让人用一小时判断：切出来的段，单看能不能懂。
产出：
- `src/yuqing/unitize/review.py`
- `tests/t13_review_test.py`
规则：
1. `yuqing unitize review --channel … --day … --n 50 --seed 1 --out review.html`
2. 单文件 HTML，手机可读；每段先显示只读上下文（灰色），再显示正文。
3. 每段两个按钮“看得懂”“看不懂”，页面底部实时显示比例；结果可导出为一段 JSON 文本供复制，不联网、不落盘。
4. 作者显示为段内代号（甲、乙、丙），不显示名字或哈希。
验收（全部通过才算完成）：
- `pytest -q tests/t13_review_test.py`：页面含 50 段；同 seed 结果相同；页面里搜不到作者名与哈希
之后的人工闸门 G1（试切 50 段）：人看 50 段，“单看这一段能看懂”达到九成算过；不到就调间隔和重叠句数重出。 这一步由人做，不要替人做。
完成后：提交、勾掉清单，接着做本阶段的下一张；阶段做完或遇到闸门再停。
```
