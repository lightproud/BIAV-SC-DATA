# T10 规范化

```text
【工单 T10】规范化
阶段：1　依赖：T01
目标：把各平台原文读成同一张 `messages` 表，后面所有层只认这张表。
产出：
- `src/yuqing/normalize/`
- `config/communities.toml`、`config/bots.txt`
- `tests/t10_normalize_test.py`
- 表 `messages`
规则：
1. 每条原文一行，字段见数据契约 `messages`。
2. `msg_id`：平台原生 ID 的稳定哈希；没有原生 ID 就用 `raw_ref` 的哈希。
3. `author_hash` = HMAC-SHA256(`AUTHOR_SALT`, 平台 + 作者标识)，取前 16 位十六进制；作者名不落盘。
4. `community`、`server` 查 `config/communities.toml`；区服查不到就留空，不猜。
5. `day_cn` 按 UTC+8 归日，按它分区写 Parquet。
6. `raw_ref` = 相对 `LAKE_ROOT` 的路径加行号，能反查回原文那一行。
7. 增量：按文件记账（已处理到第几行）；文件追加了新行就只读新行。
8. 降级：没有回复指向则 `reply_to` 为空；判断不了附件则 `has_image` 为空。
验收（全部通过才算完成）：
- `pytest -q tests/t10_normalize_test.py`：字段与类型、重跑结果不变、`raw_ref` 可反查、同盐同人哈希相同而换盐不同
- 产出目录里搜不到任何作者名（测试里检查）
不要做：
- 不删任何行；清洗在 T11，而且只打标。
完成后：提交、勾掉清单，接着做本阶段的下一张；阶段做完或遇到闸门再停。
```
