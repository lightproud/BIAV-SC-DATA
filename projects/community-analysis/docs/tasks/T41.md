# T41 归属

```text
【工单 T41】归属
阶段：4　依赖：T40、T31
目标：新反馈点自动归到已有议题，拿不准的交小模型裁决。
产出：
- `src/yuqing/issues/assign.py`
- `tests/t41_assign_test.py`
规则：
1. 议题向量 = 该议题最近若干个已确认反馈点的要点向量均值，另存几条代表要点。
2. 相似度不低于 `tau_hi`：直接归入。
3. 介于 `tau_lo` 与 `tau_hi`：把最相近的 5 个议题的标题与定义连同要点交 `MODEL_LOW` 选择，允许答“都不是”。
4. 低于 `tau_lo` 或答“都不是”：进未归属池。
5. 归属写进 `issue_points`，带 `method`、分数与 `run_id`。两个门槛是占位值，须在金标集的“议题归属”项上校准。
验收（全部通过才算完成）：
- `pytest -q tests/t41_assign_test.py`：三条路径各有样例（FakeEmbedder 加 FakeLLM）；门槛来自配置；重跑一致
完成后：提交、勾掉清单，接着做本阶段的下一张；阶段做完或遇到闸门再停。
```
