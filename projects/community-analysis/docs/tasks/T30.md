# T30 查询层

```text
【工单 T30】查询层
阶段：3　依赖：T22
目标：在 Parquet 上提供“按任意维度切一刀”的查询，返回值自带证据。
说明：接口只依赖表结构，可用小样本在 G2 之前先做。
产出：
- `src/yuqing/query/`
- `tests/t30_query_test.py`
规则：
1. DuckDB 直接读 Parquet；不起常驻数据库服务。
2. `slice(filters, group_by, period)`：过滤项＝时间范围、社区圈、区服、渠道、语言、情绪、角度、对象、自述意向；返回每组的反馈点数、独立发言人数、按日走势、代表原文。
3. 默认只用“当前生效版本”的标注（配置里指定一组版本戳）；旧版本留着但不混算。
4. 证据信封，每个返回值都带：`sample_size`、`n_authors`、`coverage`（时间范围内已标注单元占应标单元的比例）、`versions`、`anchors`（原文出处）、`evidence_gaps`（如“只来自一个频道”）。
5. 小样本保护：某组独立发言人少于 `min_authors_cell` 时，只返回总数，不返回细分与原文。
6. 代表原文：按“强度高、作者不重复、渠道分散”取 3 到 5 条；给原文与 `raw_ref`，不给 `gist_zh`，不给作者。
验收（全部通过才算完成）：
- `pytest -q tests/t30_query_test.py`：小样本库上对已知答案；小样本保护生效
- 每个返回值都通过信封校验；返回值里搜不到作者名与哈希
完成后：提交、勾掉清单，接着做本阶段的下一张；阶段做完或遇到闸门再停。
```
